# 阶段 7：风控

**目标**：在下单和领券链路上加入实时风控，练习低延迟决策、规则引擎和流式计算。
**说明**：里程碑粒度，动工前细化。

## 任务

- [ ] risk 服务：同步决策接口，返回通过、拒绝、需验证
- [ ] 接入点：下单前、领券前、支付前；风控超时或不可用时的降级策略（放行还是拒绝，按场景定）
- [ ] 名单：黑名单、白名单、灰名单，布隆过滤器加速
- [ ] 频控：按用户、设备、IP、收货地址的滑动窗口计数
- [ ] 规则引擎：规则可配置、热更新、灰度；表达式求值（可用现成库或自己实现）
- [ ] 实时特征：消费 Kafka 订单事件，计算近 N 分钟的下单数、金额、失败率等
- [ ] 离线回溯：规则上线前用历史事件回放评估命中率和误杀率
- [ ] 决策留痕：每次决策的输入、命中规则、结果可查
- [ ] 模拟攻击流量：刷单、薅券、撞库脚本，验证拦截效果
- [ ] 延迟预算：风控决策 P99 < 20ms，压测验证

## 验收标准

- 模拟攻击流量被拦截，正常流量误杀率可量化。
- 风控服务故障时主链路按预案降级。
- 规则变更无需发布服务。

## 面试考点

实时风控的架构；规则引擎设计；滑动窗口计数的实现；布隆过滤器；特征计算的一致性与延迟；同步拦截与异步处置的取舍；风控自身的高可用。
