# 阶段 8：优惠券

**目标**：加入优惠券业务，练习更复杂的多资源一致性（订单、库存、券三方）。
**说明**：里程碑粒度，动工前细化。

## 任务

- [ ] 数据模型：券模板、券批次、用户券、核销流水
- [ ] 券类型：满减、折扣、无门槛；适用范围与有效期
- [ ] 发券与领券：高并发抢券，防超发、每人限领（与库存扣减方案对比复用）
- [ ] 下单用券：金额计算、多券叠加与互斥规则、最优券推荐
- [ ] 核销一致性：下单时锁券，支付成功核销，取消或关单时退券，全流程幂等
- [ ] 把券纳入现有 Saga 与对账任务
- [ ] 部分退款时的券与金额分摊
- [ ] 券过期处理：批量过期任务、到期提醒
- [ ] 用户券表的分片方案
- [ ] 压测与故障实验：抢券场景、核销过程中注入故障

## 验收标准

- 抢券压测零超发、不超过限领数。
- 任何故障场景下不出现「券用了订单没成」或「订单取消了券没退」，对账可发现并修复差异。
- 金额计算有完整的表驱动测试。

## 面试考点

多资源的分布式事务编排；金额分摊与精度；规则引擎的初步设计；营销系统的防刷。
