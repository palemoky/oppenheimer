# 阶段 11：Rust 优化（可选）

**目标**：在压测证明的热点位置用 Rust 重写，积累 Rust 经验，并得到有数据支撑的 Go 与 Rust 对比。
**说明**：可选阶段。先有测量，再决定改哪里；没有数据证明是瓶颈的地方不改。

## 候选位置（按阶段 3 的火焰图最终确定）

- 网关限流器或整个网关的转发路径
- 风控规则表达式求值
- 订单号生成、分片路由等高频小函数（收益可能很小，适合入门）
- 一个独立的高性能组件，如延迟队列或限流 sidecar

## 任务

- [ ] 从压测数据里选定 1 到 2 个目标，写 ADR 说明选择依据和预期收益
- [ ] 确定集成方式：独立服务（gRPC）、sidecar，或 cgo/FFI，对比各自的开销
- [ ] Rust 实现，含单元测试和基准测试
- [ ] 接入可观测（指标、链路）
- [ ] 同条件对比压测：吞吐、延迟分位数、CPU、内存、尾延迟（GC 的影响）
- [ ] 写对比总结：收益、代价、是否值得

## 验收标准

- 有同条件下的对比数据和结论，哪怕结论是「不值得」。

## 面试考点

Go 与 Rust 的内存模型和并发模型对比；GC 对尾延迟的影响；所有权与生命周期；tokio 异步运行时与 goroutine 调度的对比；跨语言调用的开销。
