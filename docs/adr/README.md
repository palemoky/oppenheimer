# 架构决策记录（ADR）

每个影响架构或难以回头的决定写一篇，文件名 `NNNN-简短标题.md`。

模板：

```markdown
# ADR-NNNN：标题

- 状态：提议 / 已采纳 / 已废弃（被 ADR-XXXX 取代）
- 日期：YYYY-MM-DD

## 背景
要解决什么问题，有哪些约束。

## 决定
选了什么。

## 备选方案
考虑过什么，为什么没选。

## 后果
带来的好处、代价，以及什么情况下应该重新评估。
```
